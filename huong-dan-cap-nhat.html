Trước tiên — Sao lưu
Luôn sao lưu trước khi cập nhật.

Vào menu Hệ thống → Sao lưu & Phục hồi → Tải bản sao lưu để lấy tệp .json chứa toàn bộ dữ liệu. Giữ tệp này ở nơi an toàn. Cập nhật bằng cách giải nén đè không xóa cơ sở dữ liệu, nhưng có bản sao lưu thì luôn yên tâm.

Các bước cập nhật
1

Tắt web đang chạy

Bấm Ctrl + C ở cửa sổ đang chạy web (hoặc chạy stop-server.bat nếu dùng bộ tự khởi động Windows).

2

Giải nén bản mới đè lên thư mục cũ

Mở tệp sophia-wellness-v1.8.2.zip, chép toàn bộ vào đúng thư mục dự án hiện tại và chọn Thay thế / Replace khi được hỏi. Dữ liệu nằm trong cơ sở dữ liệu PostgreSQL nên không bị đè — chỉ mã nguồn được thay mới.

3

Cài gói & chạy lệnh cần thiết (nếu có)

Mở cửa sổ lệnh trong thư mục dự án, chạy npm install, rồi xem ghi chú bản phát hành để biết có cần chạy thêm lệnh database không (bảng bên dưới).

npm install
4

Khởi động lại web

Chạy npm run dev (hoặc start-server.bat / bật lại máy nếu dùng tự khởi động). Mở lại trình duyệt tại địa chỉ quen thuộc.

npm run dev
Ở bước 3 — chạy lệnh nào?

Mỗi bản phát hành trong CHANGELOG.md đều ghi rõ thuộc loại nào. Chọn đúng dòng bên dưới:

Ghi chú bản phát hành nói… Chạy lệnh Sau đó
Chỉ sửa giao diện
Không nhắc gì tới database/quyền.
 Không cần lệnh nào
Chỉ khởi động lại web.
 Xong ngay.
“cần prisma:push”
Có thêm bảng / cột mới trong database.
 npm run prisma:push Rồi khởi động lại web.
“cần db:sync-rbac”
Có thêm quyền / phân quyền mới.

Bỏ qua prisma:push khi bản cập nhật cần nó?

Trang liên quan có thể báo lỗi hoặc để trống (ví dụ trước đây trang Nhóm hàng trắng vì thiếu cột mới). Cứ chạy lệnh trên rồi tải lại — không mất dữ liệu.

Kiểm tra đã cập nhật thành công
Góc dưới sidebar
Phiên bản 1.8.2
Nhìn góc dưới cùng thanh menu bên trái (và trang đăng nhập). Nếu số phiên bản đúng bằng bản vừa tải về là đã cập nhật xong. Nếu vẫn thấy số cũ: xóa cache trình duyệt (Ctrl + F5) hoặc kiểm tra đã giải nén đè đúng thư mục chưa.
Lưu ý thêm
Không chạy npm run db:seed hay db:clear-demo khi cập nhật.

Hai lệnh này dùng để nạp/xóa dữ liệu demo — sẽ ảnh hưởng dữ liệu thật. Cập nhật bình thường chỉ cần các lệnh trong bảng trên.

Đang dùng bộ tự khởi động Windows?

Các tệp trong scripts/windows/ vẫn giữ nguyên sau khi giải nén — không cần cài lại. Chỉ chạy install-autostart.bat lại nếu bạn đổi thư mục dự án.
